# Nudge (src)

Implementation of the Habit Shim. See the [repo README](../../README.md) for
usage, the guide format, and extension documentation.

- `Rules.cs` — `RuleGuide` record, `KnownRules` (your own analyzer metadata),
  and `RuleCatalog` (guide resolution order).
- `rules/` — shipped coaching guides, one markdown file per rule ID.
- `EXPERIMENT.md` — the protocol and results of the three-way coaching experiment.
