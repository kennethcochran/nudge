# S4047 — Generics should be used when appropriate

## Why
Non-generic collections (`ArrayList`, `Hashtable`) box every value type and
abandon compile-time type safety: each retrieval needs a cast that can fail at
runtime, and value types pay boxing costs on every store. The generic
equivalents have existed for twenty years and cost nothing to adopt.

## Do this
1. Replace `ArrayList` with `List<T>`, `Hashtable` with
   `Dictionary<TKey, TValue>`, and so on, choosing the right element types.
2. Remove the casts at retrieval sites that the old collection forced on
   callers.
3. Run the tests for the type and its consumers.

## AVOID
- Do not "fix" it by wrapping the non-generic collection in a typed facade
   that still boxes internally — the casts and the boxing remain, just hidden
   one layer down. Use the generic collection itself.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
