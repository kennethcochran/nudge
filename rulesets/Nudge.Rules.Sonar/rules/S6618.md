# S6618 — "string.Create" should be used instead of "FormattableString"

## Why
`((FormattableString)$"...").ToString(CultureInfo.InvariantCulture)` boxes the
interpolated string into a `FormattableString` object just to format it — an
allocation plus an indirection for zero benefit.
`string.Create(CultureInfo.InvariantCulture, $"...")` formats directly into the
result string with the same explicit culture control.

## Do this
1. Replace the `FormattableString` cast plus `.ToString(culture)` with
   `string.Create(culture, $"...")`, keeping the same format items.
2. Confirm the culture argument is preserved — the point is explicit culture
   control, not dropping it.
3. Check for the same cast-and-ToString pattern elsewhere in the file; it tends
   to be copy-pasted.

## AVOID
- Do not "simplify" by dropping the culture and using plain `$"..."`
   interpolation — that changes formatting to the current culture; keep the
   explicit culture via `string.Create`.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
