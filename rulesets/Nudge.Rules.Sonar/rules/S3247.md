# S3247 — Duplicate casts should not be made

## Why
Casting the same expression twice — `((Foo)x).A + ((Foo)x).B` — repeats the
work and, worse, repeats the failure mode: an `InvalidCastException` can point
at either cast, and the duplication signals a missing local.

## Do this
1. Cast once into a local: `var foo = (Foo)x;` then use `foo.A + foo.B`.
2. If the cast is really a type test, prefer pattern matching:
   `if (x is Foo foo) { ... }`.

## AVOID
- Do not "fix" it by routing one cast through `as` plus `!`
  (`(x as Foo)!.A` next to `(Foo)x.B`) — you've kept two conversions of the
  same expression in different syntax.
- Do not extract a helper method that casts internally on each call — the
  duplication (and the double failure mode) survives inside it.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
