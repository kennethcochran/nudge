# S1451 — Track lack of copyright and license headers

## Why
This is a tracking rule: it doesn't claim a bug, it reports files missing
the project's copyright/license header so the gap is visible. Unheadered
files create licensing ambiguity for anyone reusing the code. (The BLOCKER
severity reflects policy, not defect risk.)

## Do this
1. Add the project's standard header to the file — copy it verbatim from an existing conforming file; don't retype it from memory.
2. If the project has no standard header yet, that's the real fix: define one and apply it repo-wide rather than inventing per-file text.

## AVOID
- Do not paste a license header from a different project or a guessed text — a wrong header is worse than a missing one; use the project's own.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
