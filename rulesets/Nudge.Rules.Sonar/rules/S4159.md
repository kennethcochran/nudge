# S4159 — Classes should implement their "ExportAttribute" interfaces

## Why
In MEF, `[Export(typeof(IService))]` on a class that doesn't implement
`IService` registers a broken export — composition either fails at runtime or
silently provides an object that isn't the contracted type.

## Do this
1. Make the class implement the exported interface: add the interface to the
   base list and implement its members, or
2. If the export type is simply wrong, change the `[Export]` attribute to the
   contract the class actually fulfills — then verify the composition root
   expects that contract.

## AVOID
- Do not change the `[Export(typeof(...))]` argument to some interface the
  class happens to already implement when the composition root expects the
  original contract. That silences the rule by breaking the consumer — fix the
  class/attribute pair toward the contract that's actually needed.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
