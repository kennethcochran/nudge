# S1264 — A "while" loop should be used instead of a "for" loop

## Why
A `for` loop with empty initializer and iterator sections (`for (; cond;)`)
is a `while` loop in disguise. Readers expect a `for` to manage a counter, so
the empty sections are noise that slows comprehension and invite a future edit
to "fill in" an iterator that was never meant to exist.

## Do this
1. Rewrite `for (; condition;)` as `while (condition)`, keeping the body
   identical.
2. Double-check nothing was hiding in the omitted sections (by definition
   there can't be — but verify the rewrite, don't assume it).
3. Rebuild and run the tests for the affected method.

## AVOID
- This rule is purely mechanical and has no meaningful dodge: the complete
   fix is the rewrite to `while` at the flagged location.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
