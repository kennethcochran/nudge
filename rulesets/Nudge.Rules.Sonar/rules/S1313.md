# S1313 — IP addresses should not be hardcoded

## Why
An IP baked into source can't change without a rebuild and redeploy, and it
leaks infrastructure detail into the codebase. Addresses move — DHCP,
re-provisioning, failover — and configuration exists for exactly this.

## Do this
1. Move the address into configuration (`appsettings.json`, an environment
   variable, or your config provider) and read it at startup.
2. For well-known constants, use the named value (`IPAddress.Loopback`,
   `IPAddress.IPv6Loopback`) instead of the literal.

## AVOID
- Do not "fix" it by hoisting the literal into a `const string` or a
  `static readonly` field — it's still hardcoded; the value must come from
  configuration to count as fixed.
- Do not split the address into octets joined at runtime to dodge the
  detector — same hardcoded value, now harder to grep.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
