# S6678 — Use PascalCase for named placeholders

## Why
Named placeholders in format strings are matched by name, and inconsistent
casing (`{userName}` in one place, `{UserName}` in another) causes silent
mismatches and defeats text search. PascalCase is the .NET convention for
these names; following it keeps placeholders greppable and consistent.

## Do this
1. Rename the placeholders to PascalCase.
2. Update every format string and argument source that references them so
   the names agree everywhere.

## AVOID
- This rule is mechanical: rename consistently. Do not "fix" it by switching
  to positional placeholders (`{0}`) — that trades a naming problem for the
  ordering fragility positional placeholders are known for.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
