# S3251 — Implementations should be provided for "partial" methods

## Why
A `partial` method declared without an implementation is erased at compile time — every call site silently becomes a no-op. The declaration almost certainly meant to have a body somewhere; without one, the intended behavior never runs and nobody gets an error. Either the implementation is missing or the declaration is leftover.

## Do this
1. Find where the implementation was supposed to live (usually another `partial` class file) and write it there.
2. If the method is genuinely no longer needed, delete the declaration — and its call sites, which currently do nothing.

## AVOID
- Do not add an empty implementation body just to satisfy the rule — an empty body has exactly the same runtime effect as no implementation at all.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
