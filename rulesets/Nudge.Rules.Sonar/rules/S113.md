# S113 — Files should end with a newline

## Why
A file not ending in a newline breaks POSIX tooling expectations (diff,
cat, and some compilers warn) and produces noisy 'no newline at end of file'
diffs that obscure real changes. This rule flags the missing trailing
newline.

## Do this
1. Add a single newline at the end of the file.
2. Configure the editor (EditorConfig: insert_final_newline = true) so it stays fixed.

## AVOID
- Nothing to dodge here — but add exactly one newline, not a handful of blank lines.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
