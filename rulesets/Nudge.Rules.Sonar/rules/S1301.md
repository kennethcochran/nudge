# S1301 — "switch" statements should have at least 3 "case" clauses

## Why
A `switch` with one or two cases is a convoluted `if`/`else if`: all the
ceremony of multi-way dispatch with none of the payoff. The reader parses
switch syntax expecting several branches and finds a simple condition
dressed up.

## Do this
1. Rewrite as `if` / `else if` / `else`.
2. If more cases are genuinely on the way, say so in a comment — or use a
   dictionary dispatch if the branch set is about to grow.

## AVOID
- Do not add a bogus third case to reach the quota. A dead case written to
  satisfy a counter is worse than the small switch — it is misleading code
  that can never execute.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
