# S6672 — Generic logger injection should match enclosing type

## Why
`ILogger<OrderService>` injected into `PaymentService` mislabels every log
line — filters, dashboards, and anyone grepping by category see
`OrderService` for events that happened in `PaymentService`. The generic
argument is supposed to name the source.

## Do this
1. Change the injected type to match the enclosing class:
   `ILogger<PaymentService>`.
2. If the logger comes through a base-class constructor, inject
   `ILogger<DerivedClass>` at each concrete class, or deliberately use
   `ILoggerFactory.CreateLogger(GetType())`.

## AVOID
- Do not "fix" it by switching to the non-generic `ILogger` — you lose the
  category entirely instead of correcting it, and every line becomes
  unfilterable.
- Do not inject `ILogger<SomeBaseClass>` into all derived classes to "share"
  one logger — each class gets its own category.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
