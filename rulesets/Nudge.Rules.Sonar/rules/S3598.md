# S3598 — One-way "OperationContract" methods should have "void" return type

## Why
A WCF `[OperationContract(IsOneWay = true)]` method is fire-and-forget — the
client receives no response message, so any return value (or `out` parameter)
is silently discarded. A non-void signature lies to the caller about getting an
answer back.

## Do this
1. Change the return type to `void` (and remove `out` parameters if present).
2. If the caller genuinely needs the result, the operation isn't one-way —
   remove `IsOneWay = true` instead and keep the return type.
3. Update the service contract consumers so nobody is written against the
   discarded return value.

## AVOID
- Do not "keep" the return value by stashing it in a shared field the client
   polls — that's a different (worse) protocol wearing a one-way signature;
   decide whether the operation is one-way or not.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
