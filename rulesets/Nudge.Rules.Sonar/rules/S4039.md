# S4039 — Interface methods should be callable by derived types

## Why
Explicit interface implementation (`void IFoo.Bar()`) hides the method from
the class's public surface: derived classes can't call or override it, and
callers need a cast to reach it. It also subtly changes overload resolution —
the same call can bind differently depending on the static type of the
reference.

## Do this
1. Implement the interface implicitly with a public method
   (`public void Bar()`).
2. If the explicit implementation existed to resolve a genuine member-name
   clash between two interfaces, keep explicit implementation only for the
   conflicting member and make the rest public.
3. Check that derived classes can now call and override the method as
   intended.

## AVOID
- Do not "fix" it by adding a public wrapper that casts
   (`((IFoo)this).Bar()`) — that's an extra hop preserving the hiding. Make
   the interface implementation itself public.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
