# S927 — Parameter names should match base declaration and other partial definitions

## Why
Parameter names are part of the readable contract in
C#: named arguments, XML doc `<param>` tags, and IDE tooltips all show
them. When an override or partial definition renames a parameter from
the base declaration, callers using named arguments break (or bind
surprisingly), and the docs disagree with the signature.

## Do this
1. Rename the parameter in the override/partial definition to match
   the base declaration exactly.
2. Update the XML doc `<param name="...">` to match.
3. Search for named-argument call sites using the old name and update
   them.

## AVOID
- Do not rename the parameter in the override while leaving the
  base declaration (or the other partial definitions) with the old name
  — the mismatch just moves.

- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
