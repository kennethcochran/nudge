# S6798 — [JSInvokable] attribute should only be used on public methods

## Why
Blazor's JS interop locates `[JSInvokable]` methods through public
reflection. On a private or internal method the attribute compiles but the
method is unreachable from JavaScript — the call fails at runtime with no
compile-time hint about why.

## Do this
1. Make the method `public` (and `static`, unless it is invoked through a
   `DotNetObjectReference` instance).
2. Keep the method's logic where it is; only its accessibility changes.

## AVOID
- Do not add a public pass-through method that hosts the attribute and
  forwards to the still-private real method. That is the same indirection
  with an extra hop — make the method JavaScript actually calls public.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
