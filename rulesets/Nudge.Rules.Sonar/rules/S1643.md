# S1643 — Strings should not be concatenated using '+' in a loop

## Why
Strings are immutable: each `+=` allocates a new string and copies everything
accumulated so far, making the loop O(n²) in both time and garbage. For any
non-trivial iteration count this dominates the method's cost.

## Do this
1. Create a `StringBuilder` before the loop (pass a capacity if you can
   estimate the final size).
2. `Append` inside the loop instead of `+=`.
3. Call `ToString()` once, after the loop.

## AVOID
- Do not replace `+=` with `string.Concat(a, b)` inside the loop — one
  allocation-and-copy per iteration is the same O(n²), just spelled
  differently.
- Do not "fix" it by moving the `+=` into a helper method called per
  iteration — the quadratic copying moved addresses, it didn't go away.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
