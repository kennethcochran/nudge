# S2437 — Unnecessary bit operations should not be performed

## Why
The flagged bit operation cannot change its operand — `x & 0xFF` on a `byte`, `x | 0`, a shift by zero. It's either dead code or a mask written for the wrong width, and both mislead the reader about what the expression actually computes.

## Do this
1. If the operation is a no-op, delete it.
2. If the mask was meant to do something (e.g. mask a wider value), fix the mask or the operand's type so the operation is meaningful — then re-verify the surrounding logic against the corrected width.

## AVOID
- Do not "fix" it by widening the operand's type just to make the mask non-redundant — if the value can't have those bits set, the wider type is fiction and the operation is still meaningless.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
