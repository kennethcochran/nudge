# S6617 — "Contains" should be used instead of "Any" for simple equality checks

## Why
`set.Any(x => x == value)` scans element by element even when the collection
is a `HashSet<T>` with an O(1) lookup sitting right there. `Contains(value)`
uses the hash lookup directly — faster, and it signals to the reader that
membership, not a predicate, is the question.

## Do this
1. Replace `.Any(x => x == value)` (or `.Equals`) with `.Contains(value)`.
2. If the collection is a `List<T>` where you control the type, consider
   whether a `HashSet<T>` is the right structure when membership tests
   dominate.

## AVOID
- Do not keep the lambda and write `.Any(x => x.Equals(value))`. It is the
  same linear scan with different spelling.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
