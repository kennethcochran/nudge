# S3878 — Arrays should not be created for params parameters

## Why
Calling `Foo(new[] { a, b })` on a `params` method allocates an array to wrap
arguments the compiler would have wrapped anyway. The explicit array adds
noise and, when the callee only forwards the values, a pointless allocation
the reader must mentally optimize away.

## Do this
1. Call the method with the arguments directly: `Foo(a, b)`.

## AVOID
- This rule is mechanical: pass the arguments directly. Do not "fix" it by
  changing the callee's signature to take an array — that forces every
  caller into the noisy form.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
