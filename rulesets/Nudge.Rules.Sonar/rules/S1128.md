# S1128 — Unnecessary "using" should be removed

## Why
An unused `using` directive is clutter: it suggests
dependencies the file doesn't have, slows the reader's scan of what the
file actually uses, and can mask real ambiguity errors later. The fix
is deletion.

## Do this
1. Delete the flagged `using` directive.
2. Rebuild to confirm nothing referenced it indirectly (it shouldn't —
   the analyzer already checked — but the build is the proof).
3. If your IDE is configured to remove and sort usings on save, let it;
   otherwise do a pass over the file for other dead usings.

## AVOID
- Do not keep the `using` and "justify" it by fully qualifying one
  type elsewhere in the file — the directive is still unused.

- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
