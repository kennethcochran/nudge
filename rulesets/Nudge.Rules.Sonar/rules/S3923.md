# S3923 — All branches in a conditional structure should not have exactly the same implementation

## Why
When every branch of a conditional does exactly the
same thing, either the condition is meaningless (collapse the branches)
or one branch was supposed to do something different and got
copy-pasted (implement what it was meant to do). Identical branches
also train readers to skim conditionals — the day the branches do
differ, nobody will notice.

## Do this
1. Decide which case you're in: if all branches should behave the
   same, delete the conditional and keep one copy of the body.
2. If the branches were meant to differ, write the behavior each branch
   was actually supposed to have — check git history and the original
   intent, not just the duplicated text.
3. After the change, each remaining branch should be justifiable on its
   own.

## AVOID
- Do not make a trivial, meaningless edit to one branch (rename a
  variable, add a redundant check) just to make the branches textually
  different — the logic is still duplicated and you've only blinded the
  detector.

- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
