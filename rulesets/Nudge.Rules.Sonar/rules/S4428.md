# S4428 — "PartCreationPolicyAttribute" should be used with "ExportAttribute"

## Why
In MEF, `[Export]` without a `[PartCreationPolicy]`
leaves the part's lifetime (shared singleton vs. new instance per
import) to the container default, which callers can't see at the
declaration site. A part that must be non-shared — or must be shared —
should say so explicitly, or composition bugs follow from wrong
assumptions about instance identity.

## Do this
1. Decide the part's actual lifetime requirement: `Shared` (one
   instance for all importers) or `NonShared` (fresh instance per
   import).
2. Add `[PartCreationPolicy(CreationPolicy.Shared)]` (or `NonShared`)
   alongside the `[Export]`.
3. Check importers for assumptions about instance identity (mutable
   state on a shared part, or identity comparisons on a non-shared
   part) and fix those too.

## AVOID
- Do not remove the `[Export]` to dodge the rule when the part
  genuinely must be exported — that changes the composition instead of
  documenting the lifetime.

- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
