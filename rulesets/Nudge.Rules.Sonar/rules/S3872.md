# S3872 — Parameter names should not duplicate the names of their methods

## Why
`void Process(int process)` forces every use inside the body to disambiguate — `this.Process` vs `process` reads terribly — and the parameter shadows the method name, inviting exactly the confusion the naming was supposed to avoid.

## Do this
1. Rename the parameter to describe the argument it carries (`process` → `processId`, `item`, `value`, …).
2. Update the references in the method body.

## AVOID
- Do not rename the method instead when the method name is the established API — parameters are cheaper to rename than public methods.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
