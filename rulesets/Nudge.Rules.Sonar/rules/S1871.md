# S1871 — Two branches in a conditional structure should not have exactly the same implementation

## Why
Identical `if`/`else` (or switch-case) bodies mean one of three things: the
condition is pointless, one branch was supposed to differ (a copy-paste bug),
or dead code is being kept alive. Either way the reader can't tell which, and
the wrong one is invisible — the branch that should have done something
different never does.

## Do this
1. If both branches should do the same thing, delete the condition and keep one
   body.
2. If they should differ, write the actual differing behavior — the missing
   difference is the bug.
3. If the duplication is coincidental but the condition is meaningful, that is
   rare; prefer step 1, and only otherwise leave a comment explaining why both
   paths intentionally do the same thing.

## AVOID
- Do not make a meaningless edit to one branch (rename a local, add a no-op
   line) just to make the bodies textually different — the rule is flagging a
   logic smell, and you've only blinded the detector.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
