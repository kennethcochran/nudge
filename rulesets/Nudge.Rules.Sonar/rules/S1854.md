# S1854 — Unused assignments should be removed

## Why
An assignment whose value is never read — overwritten before use, or the
method ends — is either dead code or a sign the value was meant to be used
and wasn't. Either way it lies about the data flow: a reader assumes the
computed value matters.

## Do this
1. If the value is genuinely unneeded, remove the assignment. Keep the
   right-hand call only if it has side effects the code depends on.
2. If the value was meant to be used, wire it into the logic that needs it —
   the diagnostic may have found a real bug.

## AVOID
- Do not "use" the value with a discard (`_ = result;`). That is dead code
  in a costume: the assignment still computes something nobody needs.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
