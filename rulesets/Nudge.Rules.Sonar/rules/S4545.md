# S4545 — "DebuggerDisplayAttribute" strings should reference existing members

## Why
`[DebuggerDisplay("{nmae}")]` with a typo'd or removed member renders as a literal error string in the debugger — the display attribute fails exactly when you're debugging, which is the one moment you need it to work.

## Do this
1. Fix the placeholder to reference the actual member name (field, property, or method).
2. If the member was renamed, update the attribute; if it was deleted, point the display string at its replacement.

## AVOID
- Do not "fix" it by deleting the `DebuggerDisplay` attribute when a corrected display would help — the attribute is useful; repair the reference instead.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
