# S1659 — Multiple variables should not be declared on the same line

## Why
`int x = 1, y = 2;` compresses two declarations into one line, which hides
the second variable from scanners (and from diff/review tools that work
line-by-line), and it invites mismatched initializers (`int x = 1, y;` — is
`y` meant to be uninitialized?). One declaration per line makes each
variable's type and initializer unambiguous.

## Do this
1. Split into one declaration per line, each with its own initializer where
   applicable.
2. While splitting, check each variable actually needs the shared type —
   the single-line form sometimes hid that they didn't.

## AVOID
- Do not keep them on one line separated by semicolons or spacing tricks;
  the rule is about one declaration per line, not about which separator you
  use.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
