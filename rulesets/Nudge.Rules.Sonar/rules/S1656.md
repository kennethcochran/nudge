# S1656 — Variables should not be self-assigned

## Why
`x = x;` does nothing — it's a typo for `this.x = x` (field vs. parameter) or
a leftover from a bad merge. Either way, the assignment that was intended
never happens, and the code compiles cleanly while being wrong.

## Do this
1. If it meant to assign a field or property from a parameter, qualify it:
   `this.count = count;` (or rename the parameter to remove the shadowing).
2. If both sides really are the same variable, delete the statement.

## AVOID
- Do not "fix" it by inserting a no-op in between (`var t = x; x = t;`) —
  still a self-assignment with extra steps.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
