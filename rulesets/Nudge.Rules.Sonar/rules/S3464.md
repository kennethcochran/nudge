# S3464 — Type inheritance should not be recursive

## Why
The inheritance graph contains a cycle (`A : B` while `B : A`, possibly through intermediaries). The type system cannot lay out either type — this is uncompilable by design, and it marks a modeling mistake: two types that were meant to share a contract, not inherit from each other.

## Do this
1. Determine the intended relationship and extract the shared contract into an interface or a common base class that both types use.
2. Restructure so the hierarchy is a DAG — verify no other path reintroduces the cycle.

## AVOID
- Do not "fix" it by merging the two classes into one giant class just to delete the cycle — you lose the abstraction the two types were modeling; extract the shared contract instead.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
