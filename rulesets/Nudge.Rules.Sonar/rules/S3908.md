# S3908 — Generic event handlers should be used

## Why
A custom `delegate void OrderShippedHandler(object sender,
OrderShippedEventArgs e);` duplicates what
`EventHandler<OrderShippedEventArgs>` already is — every custom delegate is a
new type name consumers must learn, and it breaks interop with code expecting
the standard pattern.

## Do this
1. Delete the custom delegate type.
2. Declare the event as
   `public event EventHandler<TEventArgs>? Name;`.
3. Update raise sites to `(this, args)` and subscribers — the signatures are
   compatible, so this is mechanical.

## AVOID
- Do not keep the custom delegate as a `using` alias
   (`using OrderShippedHandler = EventHandler<...>;`) "for readability" — one
   canonical spelling; delete the custom name.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
