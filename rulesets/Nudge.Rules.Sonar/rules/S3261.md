# S3261 — Namespaces should not be empty

## Why
An empty `namespace Foo { }` (or a file-scoped `namespace Foo;` with
nothing under it) is scaffolding that never got used, or the remains of a
type that moved away. It adds a node to the namespace tree that contains
nothing, confusing navigation and namespace completion in the IDE.

## Do this
1. Delete the empty namespace declaration entirely.
2. If a type is *supposed* to live there, move the type into it instead of
   deleting — check whether the diagnostic fired on the wrong half of an
   incomplete move.
3. Remove now-unused `using` directives that only existed to reach the empty
   namespace.

## AVOID
- Do not "fill" the namespace with a placeholder comment or an empty class
  to make it non-empty — an empty namespace with a comment in it is still
  an empty namespace.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
