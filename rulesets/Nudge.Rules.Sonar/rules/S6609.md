# S6609 — "Min/Max" properties of "Set" types should be used instead of the "Enumerable" extension methods

## Why
`SortedSet<T>` maintains its extremes in the tree structure, so its `Min`
and `Max` properties are O(1). Calling the `Enumerable.Min()` extension
method on the same set walks every element — O(n) work for a value the set
already knows.

## Do this
1. Replace `set.Min()` / `set.Max()` extension-method calls with the
   `.Min` / `.Max` properties.

## AVOID
- This rule is mechanical: the complete fix is using the property. Do not
  "fix" it by materializing the set to a list first — that adds an
  allocation on top of the wasted walk.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
