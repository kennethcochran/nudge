# S3240 — The simplest possible condition syntax should be used

## Why
if (x == true), flag ? true : false, !!value — redundant boolean syntax
adds noise that slows every reader and hides the actual condition being
tested. This rule flags conditions that can be written more simply.

## Do this
1. Apply the simplification the rule suggests: drop == true / == false, collapse c ? true : false to c, remove double negation.
2. Re-read the simplified condition once to confirm it still says what was intended, then leave it alone.

## AVOID
- There is no meaningful dodge for this rule — the simplification is the fix. Do not 'simplify' by extracting the condition into a misleadingly named helper that obscures what is being tested.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
