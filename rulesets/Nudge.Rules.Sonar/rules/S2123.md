# S2123 — Values should not be uselessly incremented

## Why
`count = count++;` increments `count` and then immediately overwrites it with
the pre-increment value — the increment is discarded and the variable silently
never changes. It's almost always a typo for `count++`, and the surrounding
logic (loop bounds, counters) then runs on a stale value.

## Do this
1. Decide the intent: if you wanted to increment, write `count++;` (or
   `++count;`) as a standalone statement.
2. If the assignment was somehow intentional, write it plainly so the next
   reader doesn't "fix" it back into the bug.
3. Check for the same pattern nearby — it tends to come from the same editing
   session.

## AVOID
- Do not "fix" it by changing `count = count++` to `count = ++count` — that
   invents new semantics the original code never expressed; write the plain
   increment the author meant.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
