# S2306 — "async" and "await" should not be used as identifiers

## Why
async and await are contextual keywords: using them as identifiers (var
async = true;) compiles today but turns every nearby line into a parsing
puzzle, and breaks the moment the code is refactored into a real async
method. This rule flags them used as identifiers.

## Do this
1. Rename the identifier to what it actually means — isAsync, awaitedCount, runAsync — picking the name that describes the data, not the keyword you borrowed.
2. Search the file for other contextual-keyword identifiers while you're at it.

## AVOID
- Do not rename to @async — the verbatim-identifier escape compiles, but the name still reads as the keyword and the confusion (and the future breakage) is unchanged.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
