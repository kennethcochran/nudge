# S4663 — Comments should not be empty

## Why
An empty `//` or `/**/` is either a deleted comment whose marker survived,
or a placeholder someone meant to fill in and forgot. Either way it adds
visual noise and, in the placeholder case, silently documents nothing — the
reader slows down for a comment that says nothing.

## Do this
1. Delete the empty comment if there's nothing to say.
2. If it marks a spot needing documentation, write the actual comment now —
   a TODO with a concrete next step beats an empty marker.

## AVOID
- Do not "fill" it with a space, a period, or `// ...` — that's an empty
  comment with camouflage.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
