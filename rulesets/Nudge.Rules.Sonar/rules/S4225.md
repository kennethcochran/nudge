# S4225 — Extension methods should not extend "object"

## Why
An extension method on `object` appears on *every* type in IntelliSense — maximum pollution for minimum benefit — and it can shadow or hijack calls meant for more specific overloads. If it works on everything, it belongs nowhere in particular.

## Do this
1. Extend the most specific type the method actually needs — the interface or base class whose members it uses.
2. If it genuinely works on anything, make it a plain static helper method instead; call sites stay explicit.

## AVOID
- Do not "fix" it with a generic (`this T obj where T : ...`) — the extension still appears everywhere the constraint allows, which is usually everywhere.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
