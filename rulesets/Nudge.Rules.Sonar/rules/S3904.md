# S3904 — Assemblies should have version information

## Why
An assembly without version attributes can't be distinguished from any other
build of itself — binding redirects, deployment diagnostics, and "which build
is actually in production?" all break down.

## Do this
1. Set the version in the project file (`<Version>`, `<AssemblyVersion>`,
   `<FileVersion>`) or `AssemblyInfo` so it flows into the built assembly.
2. Make sure the version actually changes per release — tie it to the
   build/release pipeline (CI build number, GitVersion, or similar).

## AVOID
- Do not hardcode a placeholder like `1.0.0.0` or `0.0.0.0` and never bump
  it. A version that never changes identifies nothing — the same diagnostic
  blindness with extra steps.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
