# S2761 — Doubled prefix operators "!!" and "~~" should not be used

## Why
`!!x` (double negation) and `~~x` (double bitwise complement) are no-ops —
they compile but change nothing. They are almost certainly a typo for `!=`,
or debris from another language's idiom. Either way the code doesn't do what
a reader assumes, and the real intent is lost.

## Do this
1. Read the surrounding code and determine the intent: if it meant
   not-equals, write `!=`; if the doubling was accidental, remove it.
2. Add a test pinning the intended behavior so the intent can't silently
   drift again.

## AVOID
- Do not "fix" it by adding parentheses (`!(!x)`) — the double negation is
   still a no-op, just better formatted. Write what was meant.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
