# S4214 — "P/Invoke" methods should not be visible

## Why
**This rule is deprecated; use S4200 instead.** Public P/Invoke methods
expose raw native entry points to every caller, bypassing any managed
validation or lifetime management you built around them. The replacement
rule S4200 carries the same guidance under active maintenance.

## Do this
1. Treat this finding as an S4200 finding: make the P/Invoke method
   `private` and expose a managed wrapper that validates arguments,
   manages handle lifetimes, and translates native errors into exceptions.
2. If the rule fires in CI, replace S4214 with S4200 in the active profile
   rather than carrying a deprecated rule ID forward.

## AVOID
- Do not just change `public` to `internal` and call it done. Assembly-wide
  visibility still exposes the raw native signature to every type in the
  assembly; the wrapper is the fix, not the access modifier tweak.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
