# S3992 — Assemblies should explicitly specify COM visibility

## Why
An assembly without an explicit `[assembly:
ComVisible(...)]` leaves COM visibility to the default (false, but
implicitly): every public type's COM exposure is then decided by
accident rather than intent, and a future default change or a
type-level attribute can silently alter the COM contract.

## Do this
1. Add an explicit assembly-level attribute in `AssemblyInfo` (or the
   project file): almost always `[assembly: ComVisible(false)]`.
2. Mark only the types that are genuinely part of the COM contract with
   `[ComVisible(true)]`, with explicit GUIDs and interfaces.
3. Rebuild and confirm the type library surface is exactly what you
   intend — no more, no less.

## AVOID
- Do not set `[assembly: ComVisible(true)]` just to make the warning
  go away — opting the whole assembly in exposes every public type to
  COM. Be explicit and deliberate: deny by default, allow per type.

- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
