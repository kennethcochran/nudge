# S2326 — Unused type parameters should be removed

## Why
A type parameter that's never used in the signature or body
(`void Foo<T>(int x)`) is API noise — callers must supply or infer a
meaningless argument, and readers hunt for a use that doesn't exist. It's
usually a leftover from a refactor that removed the generic usage but not the
parameter.

## Do this
1. Remove the unused type parameter from the declaration.
2. Fix up call sites (explicit type arguments that are now invalid).
3. If the parameter was "reserved for future use", delete it anyway — generics
   are easy to add back when the future arrives.

## AVOID
- Do not add a dummy use of the parameter (`typeof(T)` in a throwaway line, a
   fake cast) to make it "used" — the parameter is still meaningless; remove
   it.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
