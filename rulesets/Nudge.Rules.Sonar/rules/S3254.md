# S3254 — Default parameter values should not be passed as arguments

## Why
`Foo(x, someDefault)` where the argument equals the parameter's declared
default is noise — it restates what the signature already says. Worse, when the
default later changes, the call site silently keeps the old value instead of
following the new default.

## Do this
1. Delete the redundant argument and let the default apply: `Foo(x)`.
2. If the call site passes the value because it *differs* from the default in
   some configurations, make that explicit with a named constant — but if it
   equals the default, delete it.
3. Scan nearby call sites for the same restated default.

## AVOID
- Do not "fix" it by changing the parameter's default value to something else
   so the argument is no longer redundant — that changes every other caller's
   behavior to satisfy one call site.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`. Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
