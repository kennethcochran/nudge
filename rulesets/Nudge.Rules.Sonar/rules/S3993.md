# S3993 — Custom attributes should be marked with "System.AttributeUsageAttribute"

## Why
Without `[AttributeUsage]`, a custom attribute can be applied anywhere — including multiple times on the same target or on targets where it's meaningless — and consumers can't discover the intended usage by reflection. The attribute's contract is undocumented where it matters most.

## Do this
1. Add `[AttributeUsage(...)]` to the attribute class with the valid targets (e.g. `AttributeTargets.Class | AttributeTargets.Method`).
2. Set `AllowMultiple` and `Inherited` deliberately according to how the attribute is actually consumed.

## AVOID
- Do not apply `[AttributeUsage(AttributeTargets.All)]` blindly to silence the rule — that's the default behavior spelled out; restrict to the targets the attribute is actually designed for.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
