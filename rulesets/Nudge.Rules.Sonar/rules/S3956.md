# S3956 — "Generic.List" instances should not be part of public APIs

## Why
Exposing `List<T>` in a public signature locks callers into a concrete, fully mutable collection: you can't later return a lazy sequence or an immutable snapshot without breaking them, and callers can mutate state you thought was yours.

## Do this
1. Change the public signature to the least-powerful abstraction that works: `IEnumerable<T>`, `IReadOnlyList<T>`, or `IReadOnlyCollection<T>`.
2. Keep using `List<T>` internally; convert at the boundary (`.AsReadOnly()` / `.ToList()` as appropriate).
3. Treat it as a breaking change for implementers and note it in release notes.

## AVOID
- Do not return `List<T>` but document "please don't modify it" — documentation doesn't stop mutation.
- Do not switch to `IList<T>` — it's still fully mutable; pick a read-only abstraction or `IEnumerable<T>`.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
