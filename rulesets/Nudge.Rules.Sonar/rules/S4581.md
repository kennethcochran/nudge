# S4581 — "new Guid()" should not be used

## Why
`new Guid()` doesn't generate anything — it returns `Guid.Empty` (all zeros).
Anyone reading it as "create a new unique identifier" is misled, and the
resulting duplicate keys corrupt whatever the GUID was supposed to identify.

## Do this
1. If you need a unique identifier, use `Guid.NewGuid()`.
2. If you meant the empty value, write `Guid.Empty` so the intent is explicit.

## AVOID
- Do not replace it with `new Guid("00000000-0000-0000-0000-000000000000")`.
  That is `Guid.Empty` spelled verbosely — the same value with less clarity.
  Use the named constant.
- Do not suppress with `#pragma warning disable` or `[SuppressMessage]`.
  Suppression of analyzer diagnostics is forbidden by the project's AGENTS.md.
